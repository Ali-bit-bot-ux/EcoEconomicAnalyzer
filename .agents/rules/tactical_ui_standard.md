# TACTICAL UI & DESIGN SYSTEM STANDARD (Palantir / Linear / TradingView Aesthetic)

## 1. Философия дизайна
Интерфейс AgriCascade — это не студенческий сайт и не шаблонная поделка из нейросети, а **научно-аналитическая платформа уровня Palantir Foundry / Bloomberg Terminal / Sentinel Hub**.
Дизайн должен вызывать у жюри ощущение строгого, дорогого космического ситуационного центра.

## 2. Ключевые правила визуала

### А. Цветовая палитра (Deep Obsidian & Micro-Accents)
- **Фон приложения:** Глубокий обсидиановый градиент `linear-gradient(180deg, #070B12 0%, #0A0F1D 100%)`.
- **Стеклянные панели (Glassmorphism):** `background: rgba(13, 20, 38, 0.65); backdrop-filter: blur(16px); border: 1px solid rgba(255, 255, 255, 0.07);`.
- **Акценты:**
  - Системный акцент: `#00E5FF` (кибер-циан) и `#7C4DFF` (ультрамарин).
  - Норма / Безопасность: `#00E676` (эмеральд).
  - Предупреждение / Стресс: `#FFB300` (янтарный).
  - Критический риск / Дефицит: `#FF3D71` (карминовый).
- **Запрет:** Никаких ядовитых сплошных кислотных заливок или белых фонов.

### Б. Картография (Dark Tactical Cartography)
- **Запрещено использовать стандартный `tiles="OpenStreetMap"`** (выглядит дешево и мультяшно).
- **Обязательно использовать `CartoDB dark_matter`** для всех карт Folium.
- На темной матовой подложке цветные полигоны районов и маркеры элеваторов светятся как реальные радарные слои спутника Sentinel-1 SAR.

### В. Типографика (Micro-Typography)
- Шрифт интерфейса: `Inter`, `system-ui`.
- Числовые показатели и метрики: `font-variant-numeric: tabular-nums` и моноширинный акцент (`JetBrains Mono` / `monospace`).
- Заголовки блоков: `text-transform: uppercase; letter-spacing: 0.08em; font-size: 0.78rem; color: #94A3B8;`.

### Г. Графика Plotly (TradingView Aesthetic)
- Сетки осей: почти невидимые (`rgba(255, 255, 255, 0.05)`).
- Фон графиков: полностью прозрачный `rgba(0, 0, 0, 0)`.
- Плавные скругленные сплайны (`shape: 'spline'`) вместо угловатых ломаных линий.
- Кастомные минималистичные легенды.
