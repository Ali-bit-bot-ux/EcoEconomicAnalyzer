# Feature 04: Национальный космический контур KazEOSat-1 / KazEOSat-2

**Секция:** Космос и ДЗЗ (Республиканский финал «Дарын»)  
**Статус:** Phase 3.5 (Космический прорыв)  
**Партнерский контекст:** АО «НК Қазақстан Ғарыш Сапары» (Национальный оператор космической системы ДЗЗ РК)

---

## 1. Зачем это нужно проекту?

На Республиканском финале жюри секции «Космос» в первую очередь оценивает **связь исследования с космической отраслью Республики Казахстан**. 
Использование только европейских (ESA) и американских (NASA) спутников вызывает у жюри резонный вопрос: *«Почему вы не используете отечественные космические аппараты?»*

Интеграция концепции **Cross-Constellation Fusion** (слияние разнородных спутниковых созвездий) превращает AgriCascade в прикладной прототип для национальной космической программы РК.

---

## 2. Космическая группировка Казахстана: Характеристики КА

| Параметр | KazEOSat-1 (Отечественный) | KazEOSat-2 (Отечественный) | Sentinel-1 SAR (ESA) | NASA SMAP (США) |
|---|---|---|---|---|
| **Тип съемки** | Оптико-электронная (высокое разрешение) | Оптико-электронная (среднее разрешение) | Радарная микроволновая (SAR, C-band) | Радиометрическая микроволновая (L-band) |
| **Орбита** | Солнечно-синхронная, 675 км | Солнечно-синхронная, 630 км | Солнечно-синхронная, 693 км | Солнечно-синхронная, 685 км |
| **Разрешение** | **1 метр** (панхром) / **4 м** (мультиспектр) | **6.5 метров** (5 спектральных каналов) | 10–20 метров (всепогодный) | 9–36 км (почвенная влага) |
| **Полоса захвата**| 20 км (точечная съемка) | 77 км (региональная съемка) | 250 км (широкий охват) | 1000 км (глобальный охват) |
| **Роль в системе** | **Макро-триггер (Sentinel + SMAP)** выявляет аномалию $\to$ **KazEOSat-1/2** получает целеуказание на детальную съемку границ полей и очагов эрозии. |

## 3. Архитектура двухуровневого космического конвейера (Cascade Tasking)

```
┌─────────────────────────────────────────────────────────────┐
│ 1-й Уровень (Макро-мониторинг / Космос):                   │
│ Sentinel-1 SAR (250 км) + NASA SMAP                         │
│ Обнаруживают корневой стресс и аномалию SMAI < -1.5        │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 2-й Уровень (Целеуказание / Tasking Algorithm):             │
│ Система вычисляет полигон критического риска и формирует    │
│ Tasking Request для космических аппаратов KazEOSat-1 / 2    │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 3-й Уровень (Субметровая верификация / ҚазҒарыш):           │
│ KazEOSat-1 (1 м) валидирует границы очага засухи,           │
│ солончаковые пятна и трещины почвы на микроуровне           │
└─────────────────────────────────────────────────────────────┘
```

## 4. Что отображается в дашборде (UI Спецификация)

В модуле космической аналитики появляется панель **«🛰️ Қазақстан Ғарыш Сапары: KazEOSat Tasking»**:
1. Карточка статуса КА:
   * **KazEOSat-1:** Статус: На орбите (675 км), угол наклона 98.2°. Доступное окно субметровой съемки (1м): `16 ч 45 мин`.
   * **KazEOSat-2:** Полоса захвата 77 км. Покрытие полигона: `100%`.
2. Кнопка интерактивного моделирования:  
   *«Сформировать полетное задание (Tasking Request) для KazEOSat по координатам аномалии»* $\to$ генерация метаданных съемки (угол крена аппарата, координаты полигона, спектральные каналы RedEdge/NIR).
