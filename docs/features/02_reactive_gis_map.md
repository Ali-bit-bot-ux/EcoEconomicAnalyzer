# Feature 02: Реактивная интерактивная ГИС-карта

**Статус:** Phase 4 (Запланировано)  
**Компоненты:** `dashboard/app.py`, `streamlit-folium`, `folium`

---

## 1. Проблема текущей реализации
Жюри на предыдущих этапах отметило: «Карта непонятная, кажется, что данные не меняются».
Причины:
- Слой Folium перерисовывается целиком со сбросом зума при каждом взаимодействии со страницей.
- Отсутствует динамическая связь между слайдером «Стресс-тестирование влажности» и цветом районов.
- Нет всплывающих подсказок (tooltips) с детальной агрономической диагностикой.

---

## 2. Архитектура реактивной карты

### А. Динамическая палитра риска (Risk Choropleth)
Каждый район раскрашивается в зависимости от результирующего индекса риска $R \in [0, 100]$:
- 🟢 **Низкий риск ($R < 35$):** Нормальное развитие биомассы, влажность почвы в пределах климатической нормы.
- 🟡 **Умеренный стресс ($35 \le R < 65$):** Снижение влажности на 1–1.5$\sigma$, необходим мониторинг и подготовка листовых подкормок.
- 🔴 **Критическая засуха ($R \ge 65$):** Корневой дефицит, угроза потери более 25% урожая.

### Б. Что меняется при движении слайдера стресс-теста?
Слайдер: `Снижение влажности почвы: 0% ... -50%`
- При $0\%$: базовое историческое состояние года.
- При $-25\%$: 40% районов переходят из желтой зоны в красную.
- При $-50\%$: экстремальный сценарий (аналог 2021 г.), 80% пашни в красной зоне.
- **Главное:** Метрика *«В зоне повышенного риска: X хозяйств»* мгновенно пересчитывается без задержек.

### В. Состав тултипа при клике на район:


## 3. Требования к производительности
- Использовать `folium.GeoJson` с оптимизированными упрощенными полигонами (Douglas-Peucker tolerance = 0.01), чтобы карта грузилась мгновенно (< 500 мс).
- Использовать `st_folium(..., returned_objects=["last_active_drawing"])` для предотвращения лишних перезагрузок скрипта.
