## 1. Космическая погода и ионосферные искажения (Space Weather & TEC)

### Физическая проблема:
Низкочастотные микроволновые сигналы спутников ДЗЗ (особенно L-band 1.41 ГГц радиометра NASA SMAP) на пути из космоса к Земле проходят через **ионосферу** (высота 80–1000 км).  
Свободные электроны ионосферы вызывают:
1. **Фарадеевское вращение (Faraday Rotation):** поворот плоскости поляризации радиоволны, искажающий замеры влажности почвы.
2. **Ионосферную фазовую задержку сигнала:** пропорциональную полному электронному содержанию (**TEC — Total Electron Content**).
3. При геомагнитных бурях ($Kp \ge 5$) погрешность спутникового радиометра может достигать 15–20%.

### Реализация в AgriCascade:
- Интеграция индикатора космической погоды:
  * Мониторинг планетарного $Kp$-индекса геомагнитной активности (NOAA Space Weather Prediction Center).
  * Расчет уровня ионосферного искажения: $\Delta \phi \approx \frac{K}{f^2} \cdot \text{TEC}$.
  * Плашка в дашборде:
    * *«Космическая погода: Спокойная ($Kp = 1.8$). Ионосферный TEC: 14 TECU. Качество космического радиосигнала SMAP: 99.2% (валидно)»*.

## 2. 3D Space-to-Ground Data Cube (Сквозной космический срез)

Интерактивная визуализация для защиты проекта перед экспертами:

```
[ Орбита 693 км ] 🛰️ Sentinel-1 SAR (Микроволновый радарный импульс C-band)
       │
[ Высота 300 км ] 🌌 Ионосфера (Валидация по TEC / космическая погода)
       │
[ Высота 2-5 км ] ☁️ Сплошная облачность (Оптика слепа, радар проходит насквозь)
       │
[ Поверхность 0 см ] 🌱 Стеблестой (Кросс-поляризация VH, индекс RVI)
       │
[ Глубина 0–5 см ] 💧 Верхний слой почвы (Диэлектрическая проницаемость VV + NASA SMAP)
       │
[ Глубина 0–120 см ] 🌾 Корневая зона культур (Расчет дефицита влаги Quareo AWC)
```

Эта схема наглядно демонстрирует жюри космической секции, что студенты понимают **весь физический путь электромагнитного сигнала** от космической платформы до корневой системы растения на Земле.
