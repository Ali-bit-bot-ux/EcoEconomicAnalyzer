## 1. Концепция и цель
Устранить главное замечание жюри: «Вы смотрите только на СКО и только на пшеницу».  
Аналитическая система расширяется на **4 ключевые зерносеющие области Казахстана** и внедряет **динамический выбор сельхозкультур** с различными биологическими характеристиками.

## 3. Целевые культуры и биологические коэффициенты

При выборе культуры из выпадающего списка система извлекает параметры из `dataset/crops.json`:

1. **Пшеница яровая (Spring Wheat):**
   - Глубина корней: 1.2 м
   - $K_c$ (коэффициент водопотребления): 0.35 (всходы) $\to$ 1.15 (колошение) $\to$ 0.40 (созревание)
   - Критическая фаза: Выход в трубку — колошение
2. **Ячмень яровой (Spring Barley):**
   - Глубина корней: 1.0 м
   - $K_c$: 0.30 $\to$ 1.05 $\to$ 0.25 (более экономное водопотребление, -15% к пшенице)
   - Преимущество: созревает на 10–14 дней раньше пшеницы, успевая до пика июльской жары.
3. **Подсолнечник (Sunflower):**
   - Глубина корней: до 2.2 м (глубокий насос)
   - $K_c$: 0.35 $\to$ 1.10 $\to$ 0.35
   - Риск: сильно иссушает метровый горизонт, требует No-Till и снегозадержания.
4. **Лен масличный (Oil Flax):**
   - Глубина корней: 0.8–0.9 м (поверхностные)
   - $K_c$: 0.40 $\to$ 1.00 $\to$ 0.30
   - Риск: крайняя уязвимость к засухе в мае при прорастании семян.
5. **Нут / Чечевица (Chickpeas / Lentils):**
   - Глубина корней: 0.9–1.1 м
   - $K_c$: 0.40 $\to$ 0.95 $\to$ 0.30
   - Преимущество: азотфиксация, высокая засухоустойчивость.

## 4. Логика интеграции в интерфейс (UI Contract)

В боковой панели (`st.sidebar`):
```python
selected_region = st.selectbox(
    "🌍 Область анализа" if lang == "ru" else "🌍 Талдау өңірі",
    options=["СКО", "Костанайская обл.", "Акмолинская обл.", "Павлодарская обл."]
)

selected_crop = st.selectbox(
    "🌾 Целевая сельхозкультура" if lang == "ru" else "🌾 Негізгі дақыл",
    options=["Пшеница яровая", "Ячмень яровой", "Подсолнечник", "Лен масличный", "Нут / Чечевица"]
)
```

При изменении `selected_region` или `selected_crop`:
- Карта центрируется на полигоне выбранной области.
- Порог критического стресса $\text{AWC}_{\text{crit}}$ рассчитывается с учетом коэффициента $K_c$ выбранной культуры:
  $$\text{Deficit} = \text{Demand}(K_c) - \text{SMAP\_Moisture}$$
- На плашке алертов отображается статус конкретно для этой культуры.
